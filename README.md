`main.py` writes one single sentence — a childhood memory — to `/output/entry.txt`.
Standard library only, deterministic, no network, no input files.

> The last summer before they sold the house, I fell asleep on a bamboo mat under the mango tree while Grandma sang off-key, and the night air smelled of smoke, rain, and ripe fruit.
